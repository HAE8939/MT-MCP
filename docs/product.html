MT-MCP · MODEL CONTEXT PROTOCOL

公司共用的 MCP 工具箱。

§ 01

现在能做什么

连上后一次拿到全部已启用工具。Hub 不做意图路由——由模型根据工具名与描述自行选择并调用。

01 · IMAGEBED

临时图床

把图片上传到公司临时 COS，拿到约 1 天有效的公网 URL。适合跨模型传图与临时预览，不当永久图床。

imagebed_upload imagebed_list imagebed_delete
02 · CAMERA

机位标注

根据本地项目的楼层与图片清单，生成可离线打开的标注 HTML。人手点选后导出 JSON；后续导览不再走本服务。

camera_annot_validate_bootstrap camera_annot_build_html
03 · DESIGN

设计提示词

只读列出仓库内 Markdown 提示词，或按 id / slug 取正文。当前入库 7 条，覆盖效果图、情绪板、机位与软装等。

design_list_prompts design_get_prompt
TOOLS · 临时图床

上传、列出、删除

仅 jpeg / png / gif / webp；默认单张最大 8 MiB。可用 base64 或公网 https 源地址上传。返回 URL 约 1 天后由桶生命周期清理。

工具作用要点
imagebed_upload 上传一张图，返回公网 URL filename 必填
imagebed_list 按前缀列出对象 默认最多 50
imagebed_delete 按对象键删除 须在图床前缀内
TOOLS · 机位标注

先校验，再生成离线 HTML

服务端不读你的本地路径；平面图与图片以相对路径写入页面。推荐：先 validate，再 build_html，把 HTML 存到项目 01_机位标注/，浏览器里点选后导出 JSON。

工具作用模式
camera_annot_validate_bootstrap 检查楼层 / 图片清单，返回建议文件名与警告 不产出 HTML
camera_annot_build_html 生成完整标注页，默认可附空 JSON 脚手架 pano / effect
TOOLS · 设计提示词

列出元数据，按需取正文

slug 是不带 .md 的相对路径（如 floorplan/07_color_plan）。只填 id 或 slug 其一即可。

工具作用返回
design_list_prompts 列出全部提示词元数据 id / title / tags…
design_get_prompt 按 id 或 slug 取一条 Prompt · Notes

§ 03

怎么接入

设备须能访问 NAS 局域网 192.168.1.135。传输选 http / streamable-http。令牌向管理员索取，本文只用占位符。

01 · CURSOR

Settings → MCP

  1. 打开 MCP 设置，或编辑 mcp.json
  2. 合并下方片段中的 mcpServers
  3. 启用后应看到 7 个工具：3 个图床、2 个机位、2 个提示词
02 · 千问办公

自定义 / 远程 MCP

  1. 新增远程 MCP 服务
  2. URL 填下方入口地址
  3. Header 加 Authorization: Bearer <令牌>
  4. 可选传输时选 HTTP / streamable-http
http://192.168.1.135:8787/mcp
MCP.JSON · 通用片段 
{
  "mcpServers": {
    "MT-MCP": {
      "url": "http://192.168.1.135:8787/mcp",
      "headers": {
        "Authorization": "Bearer <MCP_AUTH_TOKEN>"
      }
    }
  }
}
HEALTH · 连通性自检 
curl -s http://192.168.1.135:8787/health
§ 04

使用前请知道

这些约束保证工具好用、也保证公司资产安全。与运维无关的部分，都写在这里。

局域网可达

设备须能访问 192.168.1.135。外网需先连公司 VPN（若有）。不要把 8787 暴露到公网。

令牌只放 Header

用 Authorization: Bearer … 或 X-API-Key。查询字符串会被拒绝。令牌仅公司内传阅。

图约一天过期

临时图床适合预览与跨模型传图。勿当永久图床，勿上传密钥、证件或未公开敏感截图。

机位页可离线

生成 HTML 后与 MCP 脱钩。标注与导出都在本地浏览器完成；JSON 之后交给其他流程即可。

配置一次，工具随时在手边。

把入口与令牌写进客户端，刷新工具列表即可开始。详细参数与调用示例见同目录《MT-MCP 接入说明》。
